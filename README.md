# ☕ Java Concepts Console Quiz

A lightweight, interactive command-line quiz application built in Java to test foundational knowledge of Java data types, operators, and control structures.

---

## 📌 Features

- **Core Java Topics:** Features multiple-choice questions covering data types, arithmetic operators, control structures, and String comparisons.
- **Robust Input Validation:** Uses a validation loop with `.trim()` and `.toUpperCase()` to ensure entries are strictly valid multiple-choice characters (`A`, `B`, `C`, or `D`).
- **Immediate Feedback:** Displays whether an answer is correct or incorrect along with the right answer key after each question.
- **Performance Summary:** Calculates and prints correct answers, wrong answers, and the final percentage score.

---

## 🛠️ Concepts Demonstrated

- **Control Flow:** `for` loop iteration, `while` loop for input validation, and conditional branches (`if-else`).
- **Arrays & Indexing:** Coordinated `String[]` question arrays and `char[]` answer keys.
- **Console I/O:** `java.util.Scanner` with string manipulation and character parsing.
- **Data Casting:** Explicit double casting for accurate floating-point percentage calculation.
